3. Descripción del proyecto
El proyecto consiste en desarrollar una aplicación web para apoyar la gestión administrativa de los registros de psicología del hogar san José, ubicado en la ciudad de Cochabamba, Bolivia. El sistema permitirá organizar y administrar información relacionada con las actividades del hogar, el personal, los recursos y los inventarios. El objetivo principal es facilitar el manejo de la información, mejorar la organización interna y optimizar los procesos administrativos mediante una herramienta tecnológica de fácil utilización.
