3. Descripción del proyecto
El proyecto consiste en desarrollar una aplicación web para apoyar la gestión administrativa de los registros de psicología del hogar san José, ubicado en la ciudad de Cochabamba, Bolivia. El sistema permitirá organizar y administrar información relacionada con las actividades del hogar, el personal, los recursos y los inventarios. El objetivo principal es facilitar el manejo de la información, mejorar la organización interna y optimizar los procesos administrativos mediante una herramienta tecnológica de fácil utilización.
4. Requerimientos Funcionales
°RF01: Registrar nuevos usuarios del sistema.
°RF02: Iniciar y cerrar sesión.
°RF03: Registrar, modificar y consultar información administrativa.
°RF04: Gestionar el inventario de productos y materiales.
°RF05: Registrar y consultar.
°RF06: Administrar información del personal.
°RF07: Generar reportes de los registros realizados.
°RF08: Buscar información mediante filtros.
5. Requerimientos no funcionales
°RNF01: El sistema debe tener una interfaz sencilla y fácil de utilizar.
°RNF02: La aplicación debe proteger la información mediante autenticación y permisos.
°RNF03: El sistema debe ofrecer tiempos de respuesta adecuados.
°RNF04: Debe ser compatibles con navegadores modernos.
°RNF05: La información debe almacenarse de manera segura.
°RNF06: El codigo debe estar organizado y ser facil de mantener.
°RNF07: El sistema debe permitir futuras mejoras y ampliaciones.
